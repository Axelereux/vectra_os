# Licensing decision — pending

VECTRA intends to publish source code under recognized open-source licenses. The exact license will be selected per component before code is published.

Potential considerations:
- Kernel and tightly integrated core components may benefit from a copyleft license.
- Independent tools and services may use a permissive license where that supports adoption and interoperability.
- Documentation should have a clearly stated documentation license distinct from software licenses.
- Imported code, firmware interfaces, drivers, fonts, assets, and dependencies must be reviewed for license compatibility.

No license is granted for software in this repository until a license is explicitly added to the relevant component. Public visibility alone does not grant permission to reuse, modify, or distribute the material.

The project will use SPDX identifiers in source files once component licenses are selected. See the SPDX License List: https://spdx.org/licenses/

This document is not legal advice. Licensing choices should be reviewed with qualified counsel before accepting external code contributions or distributing binaries.
