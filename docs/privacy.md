# Privacy principles

VECTRA intends to make privacy understandable and configurable.

Research requirements:
- Explain what data each service processes and why.
- Avoid mandatory cloud accounts for core local computing wherever feasible.
- Make telemetry opt-in by default during early development.
- Provide clear controls for connected services and AI features.
- Support administrative policies for managed institutional environments.
- Minimize data collection and retention.
- Document data flows, storage locations, and security boundaries.

These are design goals, not implemented guarantees.
