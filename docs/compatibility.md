# Compatibility research

Broad compatibility is a long-term objective, not a current feature.

Research tracks:
- Hardware support through documented device and driver interfaces
- Native application development and packaging
- Open standards and common file formats
- Potential compatibility layers for existing desktop applications
- Virtualization where appropriate and legally permitted

Each compatibility claim must be tied to a tested hardware or software configuration. The project will publish test results and known limitations rather than promise universal compatibility.
