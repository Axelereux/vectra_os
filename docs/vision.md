# VECTRA — Vision

## Purpose

VECTRA explores the development of an open-source operating system for desktop and laptop computers, built around an independently developed kernel and a modular architecture.

## Why

Individuals and institutions should have meaningful choice and control over the software foundations they rely on. VECTRA's long-term research areas include technological autonomy, privacy, security, accessibility, maintainability, and interoperability.

## Who it may serve

- Individuals seeking an understandable and adaptable computing environment
- Businesses requiring manageable and maintainable systems
- Educational institutions
- Public institutions with specific sovereignty, privacy, and operational requirements

These are intended audiences, not existing customers or adopters.

## Product direction

The project may provide distinct user experiences for different audiences while sharing a common, maintained technical foundation. The initial scope is desktop and laptop computers.

## Principles

1. User choice and transparent system behaviour
2. Privacy controls that can be understood and configured
3. Secure defaults and a documented security model
4. Accessibility as a design requirement
5. Open standards and interoperability
6. Public documentation and accountable development

## Non-goals for the initial prototype

- Replacing established operating systems in production
- Supporting every device or application
- Claiming government adoption or certification
- Shipping an always-on or mandatory AI assistant
- Promising compatibility before it has been tested
