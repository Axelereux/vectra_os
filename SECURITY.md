# Security Policy

VECTRA is currently at the concept and architecture-research stage. There is no production operating system or supported release.

## Reporting a vulnerability

Do not publish exploitable details in a public issue. Until a dedicated security contact and private reporting process are established, use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the repository owner privately through the contact information on their GitHub profile.

Please include:
- A clear description of the suspected issue
- Affected files, components, or commits
- Steps to reproduce, if safe to share
- Potential impact and any suggested mitigation

Please allow time for acknowledgement and coordinated disclosure. Do not test against systems or data that you do not own or have permission to assess.

## Security scope

Security requirements, threat models, secure update design, and vulnerability response procedures are still being developed. No security certification or guarantee is claimed.
